# RELAX - Luxury 24/7 In-Home Massage Services for Women

RELAX is a modern, responsive luxury web application offering 24/7 in-home spa & massage services tailored exclusively for women with verified therapists.

## ✨ Features
- **Curated Massage Menu**: Swedish, Deep Tissue, Aromatherapy, Back & Neck, Hot Stone & Reflexology.
- **Interactive Multi-Step Booking**: Service selection, custom durations, aromatic oil choices, date/slot picker.
- **Secure Client Verification**: Realistic 4-digit OTP SMS verification flow.
- **Service Detail Quick-View Modals**: Deep-dive into benefits, equipment inventory, and tiered pricing.
- **Safety & Ethics Charter**: Full 4-pillar client protection & background check charter.
- **Interactive Accordion FAQ & Live Client Reviews Carousel**.
- **Ambient Spa Soundscape**: Web Audio API solfeggio drone & crystal chime audio player.
- **100% Fully Responsive**: Optimized across all viewports (Mobile, Tablet, Laptop, Desktop).

## 🚀 Getting Started
Open `index.html` in any modern web browser or serve using a local development server (e.g. Live Server).
